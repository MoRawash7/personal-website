# Frontend Mentor Challenge

This is a solution to a challenge from [Frontend Mentor](https://www.frontendmentor.io/).

## Overview

### The Challenge

The goal of this project was to build a responsive webpage based on the provided Frontend Mentor design and match the original layout as closely as possible.

While building this project, I practiced and improved my skills in:

* Creating semantic HTML structures
* Building responsive layouts
* Using Flexbox for flexible component layouts
* Using CSS Grid for more complex page structures
* Writing maintainable and reusable styles with Sass
* Organizing CSS into a cleaner and more structured architecture
* Matching a design accurately using CSS
